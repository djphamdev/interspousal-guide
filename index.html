Why the 50% Reassessment Happened🤔 Why the Computer Messed Up

📋 Normal Rule📋 Normal Rule

💍 Spousal Exception💍 Married? Exception!

Transfers between spouses are explicitly excluded from "change of ownership" under R&T Code §63. The Prop 13 base year value stays intact — only ownership percentages change, not the tax base.Spouses = NO tax hike (Law: R&T Code §63). Prop 13 base stays same. Only names change 📝
